# 中英文句子练习工具

这是一个简单易用的中英文句子练习工具，可以帮助你练习中英文翻译。

## 功能特点

- 🎯 随机显示中文句子
- 🔍 点击显示对应的英文翻译
- 📊 实时显示学习进度
- ⌨️ 支持键盘快捷键
- 📱 响应式设计，支持手机端
- 🎨 现代化美观界面

## 使用方法

### 1. 准备数据文件

你需要准备一个CSV格式的文件，包含中英文句子对。文件格式如下：

```csv
中文,英文
你好吗？,How are you?
今天天气很好。,The weather is nice today.
我喜欢学习英语。,I like learning English.
```

**重要提示：**
- 第一行必须是表头：`中文,英文`
- 确保文件使用UTF-8编码
- 如果使用Excel，请另存为CSV格式

### 2. 使用步骤

1. 打开 `index.html` 文件
2. 点击"选择文件"按钮
3. 选择你准备好的CSV文件
4. 点击"随机中文句子"按钮开始练习
5. 需要查看答案时，点击"显示英文答案"按钮

### 3. 键盘快捷键

- **空格键**：显示下一个随机中文句子
- **回车键**：显示当前句子的英文答案

- 使用 PapaParse 库解析CSV文件
- 支持多种列名格式（中文/Chinese/chinese）
- 智能去重，确保每个句子都被练习到
- 响应式设计，适配各种设备
- 现代化UI设计，用户体验友好
